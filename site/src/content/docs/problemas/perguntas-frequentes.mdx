## Atendimento

**Posso atender pelo celular?**
Sim, pelo navegador do celular. A tela foi feita para computador; no celular use para emergências.

**Dá para dois atendentes falarem com o mesmo cliente?**
Um atendimento tem um único responsável. Outro colega pode espiar e enviar comentários internos; para responder, precisa que o atendimento seja transferido para ele.

**O cliente escreveu de novo depois de resolvido. É o mesmo atendimento?**
Não: abre um atendimento novo, na fila escolhida. O histórico antigo fica acessível em *Mostrar detalhes → Histórico* e, se a opção de histórico estiver ligada, ao rolar a conversa para cima.

**Posso apagar uma mensagem enviada?**
Sim, pelo menu da mensagem → *Deletar*. O cliente vê "mensagem apagada". Editar só é possível por alguns minutos (regra do WhatsApp).

**Para que serve "Assinar"?**
Coloca o seu nome no início de cada mensagem. Útil quando vários atendentes usam o mesmo número.

**O que é o número #000123?**
O protocolo do atendimento. Use-o com o cliente e na busca.

## Administração

**Quantos números de WhatsApp posso ter?**
Depende do pacote de canais contratado. O catálogo em Conexões → Adicionar mostra o uso e o limite de cada canal.

**QR Code ou API oficial?**
QR Code é grátis e rápido de ativar, mas depende de um celular e tem risco de bloqueio em volume alto. API oficial é estável e permite chamadas, mas cobra por conversa e exige templates. Operação principal: API oficial. Número secundário ou teste: QR Code.

**Como faço um supervisor sem dar acesso às configurações?**
Usuário com perfil *User* e **Modo supervisor** ligado.

**Como deixo um aviso de "estamos fechados"?**
Empresa → Horário de atendimento (mensagem fora do horário) e Feriados.

**Posso mandar mensagem em massa?**
O Altchat não tem disparo em massa pela interface. Pela API é possível enviar mensagens individuais a partir de um sistema externo, respeitando as regras do canal (templates na API oficial; sem spam em QR Code).

**O que acontece quando apago um usuário?**
Os atendimentos abertos dele voltam para *Aguardando* nas filas. O histórico mantém o nome. Transfira antes de apagar.

**Os dados ficam por quanto tempo?**
Conversas e mídias não expiram. Eventos de auditoria ficam 365 dias.

## Conta e acesso

**Esqueci a senha.**
Peça ao administrador da sua empresa para redefinir no cadastro do usuário.

**Em quais idiomas o Altchat está disponível?**
Português, inglês e espanhol, pelo seletor da barra superior.

**Como sei a versão que estou usando?**
As novidades de cada publicação estão em [Novidades](/novidades/).
